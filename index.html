Coverage

Press every key once. Keys turn green as soon as they register. A key that stays gray never reached the computer. A red badge means the key fired again faster than a person can press it (chatter). Chatter is tracked in every mode.

  • Use Fullscreen + lock keys to test Esc, Win/Super and keys the browser normally takes (Chrome). Hold Esc to leave.
  • Press keys one at a time. Outside locked fullscreen, Chrome can’t block Ctrl+W, Ctrl+T or Ctrl+N, so holding Ctrl while pressing W would close the tab.
  • Fn and the keyboard’s own RGB and Bluetooth keys are handled inside the keyboard and never reach the computer.
  • Media keys and the knob show up in the “Other keys detected” strip if they reach the browser.

Count test

Press every key exactly 10 times at a natural pace, in any order. Count in your head and don’t top up a key because its counter looks low. Then press Finish. Keys that registered too few presses are dropping presses. Keys with extra presses that came in faster than a person can type are chattering.

    How to read the results & fixing tips

    Chatter (double-firing)

    The switch “bounces”: one physical press is reported as two or more, usually 5–30 ms apart. A person can’t double-tap the same key faster than about 70–100 ms, so any gap below the threshold is counted as chatter. Bounces can also happen as the key is released: a re-press within 40% of the threshold (20 ms by default) after a release is counted as chatter too. Intermittent chatter (“111” → “1111” only sometimes) is the classic symptom.

    Missed presses / dead keys

    Software can’t see a press that never arrived. The count test catches these: if you pressed a key 10 times and only 8 registered, it’s dropping presses. Repeat the test to make sure it wasn’t a miscount.

    Auto-repeat

    The system repeats a key while you hold it down. That’s normal for a long hold. If a key auto-repeats when you only tapped it, it is releasing slowly or sticking.

    Fixing (Keychron V6 Max and similar hot-swap boards)

    1. Swap the suspect switch with one from a key you rarely use, then hammer-test both positions. If the fault moves with the switch, the switch is bad. If it stays at the position, suspect the socket or solder joint.
    2. Check whether Keychron Launcher or VIA lets you raise the debounce time (e.g. 5 → 10–15 ms). This often stops intermittent chatter.
    3. Test wired, 2.4 GHz and Bluetooth separately (set “Connection” before exporting). If extras only happen wirelessly, the cause is the radio link, not the switch.
    4. A worn or dirty switch can sometimes be revived with contact cleaner, but replacing it is the reliable fix.
